1. What Is a Set?

A set is a collection of objects, numbers, people, or things that are clearly defined.

The objects inside a set are called elements or members.

Example:

Let A be the set of the first five counting numbers.

A = {1, 2, 3, 4, 5}

The elements of A are: 1, 2, 3, 4, and 5.

What does "well-defined" mean?

It means that we can clearly determine whether something belongs to the set.

For example, "the set of even numbers" is well-defined. We can determine whether a number is even or not.

2. Elements and Set Notation

Sets are usually written using curly brackets: { }.

B = {2, 4, 6, 8, 10}

Set B has five elements.

Membership Symbols

∈ means "is an element of."

∉ means "is not an element of."

4 ∈ B

4 belongs to B.

5 ∉ B

5 does not belong to B.

3. Related Terms of Sets

These terms describe the size, type, or relationship between sets.

SET TYPE

Singleton Set

A singleton set contains exactly one element.

{5}

The set {5} has only one element. Therefore, it is a singleton set.

SET TYPE

Empty Set

An empty set contains no elements.

∅

It can also be written as:

{ }
ANOTHER NAME

Null Set

A null set is another name for an empty set.

∅ = { }
LIMITED

Finite Set

A finite set contains a definite, limited number of elements.

{1, 2, 3, 4, 5}

It has exactly five elements.

UNLIMITED

Infinite Set

An infinite set has an unlimited number of elements.

{1, 2, 3, 4, 5, ...}

The counting numbers continue forever.

COMPARISON

Equal Sets

Two sets are equal if they contain exactly the same elements.

A = {1, 2, 3}
B = {3, 2, 1}

A = B because order does not matter when comparing sets.

COMPARISON

Equivalent Sets

Two sets are equivalent if they have the same number of elements.

A = {1, 2, 3}
B = {a, b, c}

Both have three elements, so they are equivalent.

RELATIONSHIP

Subset

A is a subset of B if every element of A is also found in B.

A ⊆ B
A = {1, 2}
B = {1, 2, 3, 4}

Therefore, A ⊆ B.

RELATIONSHIP

Proper Subset

A is a proper subset of B when every element of A is in B, but A and B are not equal.

A ⊂ B
A = {1, 2}
B = {1, 2, 3}
RELATIONSHIP

Disjoint Sets

Two sets are disjoint when they have no elements in common.

A ∩ B = ∅
A = {1, 2, 3}
B = {4, 5, 6}
RELATIONSHIP

Overlapping Sets

Two sets overlap when they have at least one common element.

A ∩ B ≠ ∅
A = {1, 2, 3}
B = {3, 4, 5}
LARGEST GROUP

Universal Set

The universal set contains all objects being considered in a particular problem.

U = All learners being studied
Easy Memory Guide:

Singleton = one

Empty / Null = zero

Finite = limited

Infinite = never-ending

Disjoint = nothing in common

Overlapping = something in common

4. Universal Set

The universal set, represented by U, contains everything being considered in the problem.

Example:

Suppose there are 50 learners in a class. If we are studying their favorite subjects, all 50 learners belong to the universal set.

U = All 50 learners

5. What Is a Venn Diagram?

A Venn diagram is a visual way of showing sets and the relationships between them.

Circle A

Contains all elements belonging to Set A.

Circle B

Contains all elements belonging to Set B.

Overlap

The overlapping part represents elements belonging to both A and B.

Outside

The area outside both circles represents elements belonging to neither set.

6. Union — A ∪ B

The union contains everything that belongs to A, B, or both.

A ∪ B = A or B or both

Common clue words are: or, at least one, and either or both.

A = {1, 2, 3}
B = {3, 4, 5}

Therefore:

A ∪ B = {1, 2, 3, 4, 5}

7. Intersection — A ∩ B

The intersection contains elements that are common to both sets.

A ∩ B = elements in both A and B

Common clue words include: both, common, and shared.

A = {1, 2, 3, 4}
B = {3, 4, 5, 6}

Therefore:

A ∩ B = {3, 4}

8. A Only and B Only

A Only

A Only means elements that belong to A but do not belong to B.

A Only = n(A) − n(A ∩ B)

B Only

B Only means elements that belong to B but do not belong to A.

B Only = n(B) − n(A ∩ B)

9. Complement and Neither

The complement of A, written as A′, means everything in the universal set that is not in A.

A′ = U − A

Neither

For two sets, neither means elements that are outside both circles.

Neither = U − (A ∪ B)

10. 🔢 Family of Real Numbers

The real numbers are all numbers that can be represented on a number line.

The family includes natural numbers, whole numbers, integers, rational numbers, and irrational numbers.

Number Family

Natural ⊂ Whole ⊂ Integers ⊂ Rational ⊂ Real

Irrational numbers are also real numbers, but they are not rational.

Rational ∪ Irrational = Real

① Natural Numbers

Natural Numbers

Natural numbers are counting numbers.

1, 2, 3, 4, 5, ...

Examples: 7, 15, 100

In this lesson, we use 1 as the first natural number.

② Whole Numbers

Whole Numbers

Whole numbers include zero and all positive counting numbers.

0, 1, 2, 3, 4, ...

Examples: 0, 5, 20, 100

③ Integers

Integers

Integers include negative numbers, zero, and positive whole numbers.

..., −3, −2, −1, 0, 1, 2, 3, ...

Examples: −10, −2, 0, 5

④ Rational Numbers

Rational Numbers

A rational number can be written as a fraction of two integers.

a / b, where b ≠ 0

Examples:

½
¾
−2
0.5
0.75

Even whole numbers and integers are rational. For example:

5 = 5/1
⑤ Irrational Numbers

Irrational Numbers

Irrational numbers cannot be written as a fraction of two integers.

Their decimal representations continue forever without repeating a pattern.

Examples:
√2
√3
π

For example:

√2 ≈ 1.414213562...
Important:

Not every square root is irrational.

For example:

√9 = 3

Since 3 is an integer and can be written as 3/1, √9 is rational.

For a positive integer, a square root is irrational when the number under the radical is not a perfect square.

⑥ Real Numbers

Real Numbers

Real numbers include all rational and irrational numbers.

Real = Rational ∪ Irrational

Examples include:

−5
0
3
½
√2
π

11. Complete Venn Diagram Example

There are 80 ALS learners.

45 learners like LS5.

40 learners like LS6.

20 learners like both LS5 and LS6.

Step 1 — Identify the Sets

A = Learners who like LS5
B = Learners who like LS6

Step 2 — Put the Intersection First

A ∩ B = 20

Step 3 — Find A Only

45 − 20 = 25

Step 4 — Find B Only

40 − 20 = 20

Step 5 — Find the Union

n(A ∪ B) = n(A) + n(B) − n(A ∩ B)
45 + 40 − 20 = 65

Step 6 — Find Neither

80 − 65 = 15
Final Answer:

LS5 only = 25

LS6 only = 20

Both = 20

At least one = 65

Neither = 15

Check: 25 + 20 + 20 + 15 = 80 ✓

12. Important Venn Diagram Formula

n(A ∪ B) = n(A) + n(B) − n(A ∩ B)

We subtract the intersection because the common elements would otherwise be counted twice.

Easy Memory Trick:

Union = Add both sets − subtract the overlap.

13. Common Mistakes

❌ Mistake 1: Confusing Union and Intersection

Union means A or B or both. Intersection means both A and B.

❌ Mistake 2: Counting the Overlap Twice

When finding the union, subtract the intersection once.

❌ Mistake 3: Confusing "Only"

If A has 40 learners and 15 are in both, A Only is:

40 − 15 = 25

❌ Mistake 4: Assuming Every Square Root Is Irrational

Check whether the number is a perfect square.

√9 = 3

Therefore √9 is rational.
